# 🦖 مگالودون - پلتفرم تحلیل و ترید کریپتو

پلتفرم حرفه‌ای تحلیل تکنیکال و ترید کریپتو با هوش مصنوعی **ماموت**

## ✨ ویژگی‌های اصلی

### 📊 چارت حرفه‌ای
- نمودارهای تعاملی با ابزارهای قدرتمند
- رسم فیبوناچی، خط‌های روند و سطوح
- تحلیل OHLC در زمان واقعی
- چندین Timeframe (1m - 1M)

### 🤖 دستیار هوش مصنوعی
- تجزیه فوری تکنیکال
- پاسخ به سوالات تحلیلی
- توصیات بر اساس داده‌های بازار
- یادگیری از الگوهای تاریخی

### ⚡ سیگنال‌های دقیق
- تحلیل ساختار بازار (BULLISH/BEARISH/MIXED)
- شناسایی خودکار سطوح حمایت و مقاومت
- محاسبه Entry/SL/TP برای هر معامله
- نسبت Risk/Reward محاسبه‌شده

### 📈 شاخص‌های تکنیکال
- ATR (Average True Range)
- EMA (Exponential Moving Average)
- FVG (Fair Value Gaps)
- Swing Detection (HH/LH/HL/LL)

### 💰 محاسبه‌گر ریسک
- محاسبه خودکار حجم پوزیشن
- بر اساس موجودی و درصد ریسک
- حساب R:R برای هر معامله

### 🔔 هشدارهای زنده
- اطلاع‌رسانی فوری
- مراقبت‌کننده بازار 24/7
- Webhook integration

## 🚀 شروع سریع

### نیازمندی‌ها
- مرورگر جدید (Chrome, Firefox, Safari)
- اتصال اینترنت
- یک حساب Binance (اختیاری)

### نصب
```bash
git clone https://github.com/farzadashraf/megalodeon.git
cd megalodeon
# فایل index.html را در مرورگر باز کنید
```

### استفاده
1. صفحه اصلی را باز کنید
2. بر روی "ثبت‌نام رایگان" کلیک کنید
3. نماد و Timeframe را انتخاب کنید
4. تجزیه را شروع کنید!
